# 3. Технічні вимоги до апаратних ресурсів

Для коректної роботи системи прогнозування (Go-застосунок з вбудованим UI, inference та collector) потрібні такі мінімальні ресурси:

* **Процесор:** 1-2 ядра (сучасна архітектура x86-64 або ARM64)
* **Оперативна пам'ять:** від 512 МБ (TensorFlow Lite споживає мінімум пам'яті для inference)
* **Дисковий простір:** 100-500 МБ для зберігання локальної SQLite-бази даних з історією метрик (залежить від кількості вузлів)
* **Мережа:** доступ до встановленого сервера Prometheus.

Для роботи пайплайну навчання моделі (Python) потрібні додаткові ресурси (якщо навчання запускається локально):
* **Процесор:** 2-4 ядра
* **Оперативна пам'ять:** від 4 ГБ
* **Програмне забезпечення:** Python 3.9+, Go 1.21+, Docker & Docker Compose (для запуску Playground).
