# 5. Запуск програми

## 1. Запуск тестового середовища (Playground)
Для імітації серверного навантаження потрібно підняти середовище з Prometheus та Telegraf:
```bash
cd playground
docker-compose up -d
```
Це запустить кілька контейнерів з емуляцією навантаження ресурсу, а також Prometheus на порту `9090`.

## 2. Запуск бекенду та UI
Перейдіть до директорії `app/` та виконайте `make run` або компільований бінарний файл:
```bash
cd app
make run
```
За замовчуванням сервіс запущено локально (наприклад `http://localhost:8080`).

## 3. Запуск збірника метрик (якщо він запускається як окремий процес)
Якщо collector виділений окремо:
```bash
cd app/cmd/collector
go run main.go
```
