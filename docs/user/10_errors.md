# 10. Можливі типові помилки та їх уникнення

### 10.1. "No nodes found" у Dashboard або порожній графік
*   **Причина:** Відсутність зв'язку між Collector-ом та Prometheus-ом, або ж Telegraf не надсилає метрики.
*   **Рішення:** Перевірте коректність `PROMETHEUS_URL`. Скористайтеся командою `docker ps` в папці `/playground`, щоб переконатися, що контейнери запустились нормально і працює Prometheus.

### 10.2. "Model prediction failed" в логах
*   **Причина:** Не знайдено `.tflite` файла моделі або структура файлу не відповідає очікуванням CGO/вхідного фіч-вектору (feature vector).
*   **Рішення:** Переконайтеся, що артефакти (`.tflite` та `scaler.json`) лежать у правильній директорії (за замовчуванням `model/artifacts/` або інша директорія, визначена в аргументах запуску) та коректно згенерувалися скриптом Python.

### 10.3. Необґрунтовано високі/низькі прогнози, дуже низький Coverage
*   **Причина:** Модель натренована на даних із зовсім іншого датасету (наприклад, тільки високе навантаження), а застосовується для серверів зі слабкою активністю.
*   **Рішення:** Перенавчіть модель на свіжих метриках з Prometheus, що відповідають реальним серверам. Замість історії хмарних Azure VM, використовуйте локальні метрики з `playground`.

### 10.4. CGO_ENABLED Error під час запуску бекенду (Go)
*   **Причина:** Go-застосунок, який використовує TFLite, не компілюється через відключений CGO або відсутність C++ компілятора.
*   **Рішення:** Встановіть `gcc` на свій комп'ютер і встановіть змінну середовища: `export CGO_ENABLED=1`.
