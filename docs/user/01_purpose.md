# 1. Призначення ПЗ

Система призначена для:
* прогнозування пікового навантаження CPU та RAM на окремий сервер (Node);
* надання інтервального прогнозу (нижня та верхня межа);
* візуалізації та моніторингу стану навантаження вузлів у реальному часі через Dashboard;
* завчасного сповіщення операторів (через ризикові статуси SAFE, WARNING, CRITICAL) щодо ймовірних аномалій або недостатності ресурсів.
