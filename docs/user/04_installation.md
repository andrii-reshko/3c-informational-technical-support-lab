# 4. Встановлення та налаштування

Система може бути запущена з вихідного коду (Go) або розгорнута як Docker-контейнер.

## 4.1. Встановлення з початкового коду:
1. Завантажте або клонуйте репозиторій.
2. Переконайтесь у наявності встановленого **Go** (мінімум версія 1.21).
3. Перейдіть у директорію `app/`:
   ```bash
   cd app
   ```
4. Встановіть необхідні залежності:
   ```bash
   go mod download
   ```
5. Переконайтесь, що CGO увімкнено (для роботи TensorFlow Lite): `export CGO_ENABLED=1`.

## 4.2. Налаштування:
Налаштування здійснюються через змінні оточення (або конфіг файл `.env`):
* `PROMETHEUS_URL` — URL для підключення до Prometheus (наприклад `http://localhost:9090`).
* `DB_PATH` — шлях до SQLite-файлу (`metrics.db`).
* `MODEL_PATH` — шлях до `.tflite` файлу моделі.
* `SCALER_PATH` — шлях до `scaler.json`.
