# 6. Опис інтерфейсу користувача

Інтерфейс користувача (Web Dashboard) побудований на базі HTML/CSS з використанням Bootstrap та бібліотеки D3.js для візуалізації графіків в режимі реального часу (за допомогою WebSocket).

Дошка моніторингу доступна за адресою `/ui`. Вона призначена для надання швидкого огляду стану всіх контрольованих вузлів.

## Основні функції:
* **Dashboard (Головна сторінка):** Показує список серверів (вузлів), їх поточний статус, навантаження та індикатор ризику (SAFE, WARNING, CRITICAL).
![Dashboard](../media/dashboard.png)

* **Node Details (Деталі вузла):** Детальна сторінка конкретного сервера. Включає апаратну конфігурацію, поточну статистику, межі прогнозу (коридор ймовірних значень на 15 хв вперед), запас по ресурсах та інтерактивний графік навантаження.
![Node Details](../media/node_view.png)
