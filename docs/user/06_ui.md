# 6. Опис інтерфейсу користувача

Інтерфейс користувача (Web Dashboard) побудований на базі HTML/CSS з використанням Bootstrap та бібліотеки D3.js для візуалізації графіків в режимі реального часу (за допомогою WebSocket).

Дошка моніторингу доступна за адресою `/ui`. Вона призначена для надання швидкого огляду стану всіх контрольованих вузлів.

## Основні функції:
* **Dashboard (Головна сторінка):** Показує список серверів (вузлів), їх поточний статус, навантаження CPU/RAM та індикатор ризику (SAFE, WARNING, CRITICAL). Кожна картка відображає: CPU поточний % → CPU прогноз | RAM поточний % → RAM прогноз.
![Dashboard](../media/screencapture-localhost-9001-ui-2026-05-13-08_56_21.png)

* **Node Details (Деталі вузла):** Детальна сторінка конкретного сервера. Включає апаратну конфігурацію, поточну статистику CPU та RAM, окремі межі прогнозу (коридор ймовірних значень на 15 хв вперед) для кожного ресурсу, запас по ресурсах та інтерактивні графіки навантаження для CPU та RAM.
![Node Details](../media/screencapture-localhost-9001-ui-nodes-test-node-01-2026-05-13-08_55_56.png)
