# 11. Приклади роботи з програмою

### Приклад 1. Перегляд стану кластеру за допомогою UI:
Після входу на `/ui` оператор бачить таблицю з 2 тестових серверів: `test-node-01` та `test-node-02`. 
`test-node-01` завантажений "складним" завданням (наприклад, через скрипт емуляції стресового навантаження `playground/stress-server`). Його CPU дорівнює `85%`, а статус - `CRITICAL`.
Для `test-node-02` рівень використання CPU становить `15%`, статус - `SAFE`.

### Приклад 2. Збір історичних даних та створення метрик:
Адміністратор запускає collector. У фоні він робить HTTP запит:
`GET http://localhost:9090/api/v1/query_range?query=...`
Кожні 5 секунд дані записуються до SQLite БД `metrics.db`. Завдяки цьому з'являється база, з якої модель отримує ознаки для 15-хвилинного прогнозування (лаг-фічі, rolling mean/max, час доби та день тижня).

### Приклад 3. Прогнозування REST викликом (API):
Розробник тестує систему через інший сервіс за допомогою команди curl:
```bash
curl "http://localhost:8080/predict?node_id=test-node-01"
```
Відповідь у форматі JSON містить структуру з горизонтом 15 хвилин та двома значеннями (`lower_bound=70.0`, `upper_bound=95.0`), на основі яких розробник може автоматизувати масштабування контейнерів.
