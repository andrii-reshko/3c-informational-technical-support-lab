# Чекліст тестування 

## AI-система прогнозування навантаження на сервер
### v.0.1.0

## 1. Функціональне тестування

### 1.1 Тести типових сценарів

| №  | Тестові сценарії                               | 
|----|------------------------------------------------|
| 1  | Отримання списку вузлів через GET /nodes       |
| 2  | Перегляд dashboard з картками вузлів           |
| 3  | Перегляд деталей вузла (CPU, прогноз)          |
| 4  | Збір метрик кожні 5 секунд                     |
| 5  | Отримання інтервального прогнозу (lower/upper) |
| 6  | Відображення графіка історії + прогноз         |
| 7  | Автоматична реєстрація нового вузла            |
| 8  | Зберігання метрик за останні 7 днів            |
| 9  | Backfill при запуску/перебої                   |
| 10 | WebSocket оновлення даних                      |

### 1.2 Тести граничних умов

| № | Тестові сценарії                            | 
|---|-----------------------------------------|
| 1 | Немає даних для вузла (новий вузол)     |
| 2 | Менше 61 метрики для прогнозу           |
| 3 | Вузол з 0 CPU cores                     |
| 4 | Вузол з 0 GB                            |
| 5 | Графік з порожніми даними               |
| 6 | Max навантаження >100% (помилкові дані) |
| 7 | Прогноз upper > 100%                    |
| 8 | Coverage < 80%                          |
| 9 | SafeBoundary = 100 (захардкоджено)      |

### 1.3 Тести виняткових ситуацій

| № | Тестові сценарії                      |
|---|-----------------------------------|
| 1 | Prometheus недоступний            |
| 2 | SQLite БД недоступна              |
| 3 | Модель TFLite не завантажена      |
| 4 | Некоректний node_id               |
| 5 | Пустий список вузлів              |
| 6 | Метрика з нульовим timestamp      |
| 7 | Метрика з від'ємним значенням CPU |
| 8 | Відсутність файлу конфігурації    |

## 3. Тестування UI

| № | Тест                                                            | 
|---|-----------------------------------------------------------------|
| 1 | Dashboard відображає картки вузлів                              |
| 2 | Картка показує: назва, risk badge, CPU%, прогноз                |
| 3 | Risk badge: safe (зений), warning (жовтий), critical (червоний) |
| 4 | Навігація до деталей вузла                                      |
| 5 | Node Details: hardware profile (CPU cores)                      |
| 6 | Node Details: поточне навантаження CPU %                        |
| 7 | Node Details: графік історії + інтервал прогнозу                |
| 8 | Node Details: quality metrics (MAE, Coverage)                   |
| 9 | Back to dashboard кнопка                                        |
